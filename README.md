# Retail Analysis SQL Project

## Overview

This project analyzes a relational retail database containing data on products, orders, and customers. The project explores relationships in the data, aiming to find which factors are associated with return rates and profit per customer.

## Dataset

The [Retail Data](https://www.kaggle.com/datasets/hyerdrac/retail-data) dataset from [hyerdrac](https://www.kaggle.com/hyerdrac) on Kaggle was used for this project. This synthetic dataset contains five CSV files representing different tables, as well as a SQLite database.

## Tools Used

- SQLite
- SQL
- Git / GitHub
